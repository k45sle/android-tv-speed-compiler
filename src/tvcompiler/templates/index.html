Wireless debugging status

Connect to the TV

On the TV’s main Wireless debugging screen, enter its IP address and connection port. Pairing uses a separate port. “Already paired” means this service has the TV’s pairing keys saved; pairing through another ADB installation does not count.

Pair this TV

On the TV, choose Pair device with pairing code. Enter the IP:port and short code shown in that popup. This pairing port is separate from the connection port.

Choose apps to watch

Select apps to save their current versions as baselines. No compile will be queued.
